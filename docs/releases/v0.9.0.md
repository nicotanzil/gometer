GoMeter 0.9.0 adds a shared test-authoring workspace alongside the existing
personal dashboard and CLI. Team execution is not included in this milestone.

- The separate `gometer workspace serve` service supports Keycloak-compatible
  OIDC sign-in, durable PostgreSQL sessions, explicit membership and role checks,
  CSRF protection, and local sign-out. LDAP federation remains in Keycloak.
- Team Tests supports shared public configuration, creator/editor attribution,
  All/My filters, teammate search, conditional edits, independent copies and
  public-document exports. Legacy native configurations remain private.
- Managed-secret references conceal source filenames and values. Shared documents
  bind empty fields to exact reference revisions. The mounted-file reader is an
  executor building block; the authoring service never resolves workload secrets.
- Author-private PostgreSQL drafts survive browser restarts. Test and draft
  conflicts preserve edits instead of silently overwriting them. Invalid unfinished
  text stays in the tab with navigation protection. No workload document or token
  is stored in browser local/session storage.
- The team editor includes request/traffic forms, reference selectors, the existing
  journey canvas, themes, keyboard shortcuts and a guide. Secret-bound journeys
  use canvas preview because bindings currently use positional paths; Advanced
  editing requires explicit review of those paths.
- Personal-mode improvements include the Tests library, revision-safe editing and
  copies, a persistent named-worker catalog with explicit connection checks, and
  refreshed results views. Existing load execution remains available in personal
  mode and the CLI.
- Release automation now requires disposable PostgreSQL integration checks before
  packaging. It publishes executable archives/checksums and container images for
  Linux AMD64 and ARM64. Images include standard CA roots for verified HTTPS.

This is an authoring milestone, not a complete shared execution service. Durable
submissions, the serial executor, queue/ownership controls, secret resolution
and concealment during execution, and team Kubernetes deployment are pending.
The selected executor policy permits any reachable workload destination;
operators must be trusted with where they send credentials. Real company
Keycloak/LDAP and Kubernetes acceptance have not been performed.

Upgrade team databases explicitly with `gometer workspace migrate` before
starting the new service. Migration 005 adds private drafts and preserves existing
shared definitions, references and sessions. Back up operator-managed databases
before upgrading. The personal dashboard still uses its independent JSON store;
setting a database URL does not import personal files or switch it to team mode.

Verified locally: full source checks, race-enabled Go tests, binary builds,
disposable PostgreSQL upgrades/permissions/concurrency/audit checks, signed-in
Chromium authoring and draft recovery, and the existing personal dashboard browser
suite. These fixture results are not deployment or company SSO acceptance.

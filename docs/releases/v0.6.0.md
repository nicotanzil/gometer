GoMeter 0.6.0 renames the gmeter application to **GoMeter**. The executable and
demo are now `gometer` and `gometer-demo`; Go source imports use the `gometer`
module path. Dashboard storage defaults to `.gometer/`, and worker and telemetry
settings use the `GOMETER_*` environment variable names.

Before upgrading an existing installation:

- Move or copy saved dashboard data from `.gmeter/` to `.gometer/`, or start the
  new dashboard with `gometer ui -data .gmeter` to keep using the old directory.
- Rename `GMETER_WORKER_TOKEN`, `GMETER_WORKER_CA`, `GMETER_TELEMETRY_TOKEN`, and
  `GMETER_TELEMETRY_CA` to their `GOMETER_*` equivalents wherever they are set.
- Update scripts, service definitions, container references, and Kubernetes
  manifests from `gmeter` / `gmeter-demo` to `gometer` / `gometer-demo`.

The application does not automatically migrate the old workspace directory or
read the old environment variable names. Back up workspace data before moving
it. The dashboard data format and worker protocol are otherwise unchanged in
this release.
